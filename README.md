# English Typing

每日英文打字複習。直接用瀏覽器打開 `index.html` 即可（不需要伺服器）。

- 左側選日期，在文章區點一下開始打字
- 段落結尾的 `↵` 要按 Enter
- 「朗讀全文」／每段下方的「朗讀這段」：用瀏覽器內建語音念英文，可調速度（再按一次停止）
- 「單字模式」：打開後點任何一個英文單字就會念出來
- 「顯示中文」：在每段英文下面顯示中文翻譯
- 「隱藏原文」：只顯示已打的字，用來測試記憶
- Esc：重新開始
- 每篇的最佳 WPM 會存在瀏覽器裡

## 新增每日文章

在 `entries.js` 的陣列中加一筆：

```js
{
  date: "2026-10-08",
  title: "標題",
  translation: `第一段翻譯...

第二段翻譯...`, // 可省略，段落數要和英文一致
  text: `第一段...

第二段...`,
},
```
